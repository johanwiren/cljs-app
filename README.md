# Sample full-stack clj+cljs project

## Emacs

A dev-server and both clj + cljs repls will be available after running

```
cider-jack-in-clj&cljs
```

Then point your browser to http://localhost:8020

This is all you need to do, really.

You now have two REPL's up and running and Emacs/Cider keeps track of which one to use.
